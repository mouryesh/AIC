## If a judge asks one question, it will be one of these

Prepared answers for 37 of them: [`JUDGE_QA.md`](JUDGE_QA.md), which now opens
with the prior-art questions a manufacturing subject-matter expert will reach
for first. The three most likely:

**"Isn't this just the Turning Point Method?"** The mechanism is, and we cite
Li, Chang & Ni (2009) rather than claim it. We implement it as baseline B3. It
detects as well as we do — better at 50% coverage — but it scans the stations it
can measure, so a turning point inside a sensor gap is outside its output space:
0% exact on hidden sources, at every coverage level. Resolving into that gap is
the contribution.

**"How do you know the hidden state is right?"** We estimate the cycle time of a
station that has no sensor to ~3% median error, graded against ground truth the
model never sees.

**"Could this actually run in my plant?"** Five required signals, and
blocked/starved — the critical one — is a standard OEE state most plants already
record and then ignore. Run `python -m rippletwin.integrate.assess --contract`
in the meeting. Read-only at Purdue Level 3, so a pilot needs no OT change. And
an alert becomes a work order with an owner and a respond-by time, because
"nobody owns the next action" is the most-cited reason these systems fail.

**"Your simulator is built to make your method work."** It broke four of our own
designs, all documented in `METHOD.md`. A simulator built to flatter the method
would not have done that.

## What we would fix first with more time

1. **Validate the flow signature on one real line's PLC logs.** This is the only
   thing that moves the work from plausible to proven, and nothing else comes
   close in value.
2. **Generalise beyond serial topology** — parallel sub-lines and rework loops
   need the propagation matrix rebuilt from the real process graph.
3. **Strengthen the quality path.** Median rank 7 of 42 is a useful shortlist,
   not a diagnosis.
4. **Detection at low coverage.** At 25% instrumentation, exact localisation
   falls to ~12%. Honest, but that is the edge of the mechanism.
5. **Harden the placement validation.** The separability metric predicts where
   localisation fails only directionally (r ≈ 0.37, few episodes per station).
